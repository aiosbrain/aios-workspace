# AIO-952: all classic GitHub token prefixes — ghp (PAT), gho (OAuth), ghu (user-to-server),
# ghs (server-to-server), ghr (refresh) — not just the ghp/ghs pair.
gh[pousr]_[A-Za-z0-9_]{36,}
(^|[^A-Za-z0-9_-])xox[bporas]-[A-Za-z0-9-]+
# AIO-965: the `sk-` prefixes need a LEFT TOKEN BOUNDARY. Without one they match mid-word, and
# the substring "sk-" is extremely common in ordinary hyphenated prose — a real workspace tripped
# this on the Linear URL slug ".../blocker-task-tier-knot-three-home-tasks-split-scaffold-loop-
# surfaces", where "ta|sk-tier-knot-…" is 40+ token characters. A secret scanner that cries wolf
# on issue links is one people learn to ignore, which costs more than the pattern buys.
# `(^|[^A-Za-z0-9_-])` is used rather than `\b` so the ERE stays portable across GNU grep, BSD
# grep, and the JS RegExp consumer in scripts/aios.mjs. The matched text is never printed, so the
# extra leading character is harmless.
(^|[^A-Za-z0-9_-])sk-[A-Za-z0-9_-]{40,}
(^|[^A-Za-z0-9_-])sk-ant-[A-Za-z0-9_-]{20,}
aios_[A-Za-z0-9]+_[A-Za-z0-9]{24,}

# AIO-952: value-shape prefixes for providers AIOS integrates. The generic scanner rules key on
# the IDENTIFIER a value is bound to (api_key/secret/token), so a credential assigned to any
# other name is invisible to them — team-brain PR #575 proved a one-line rename flips OGR03 from
# CRITICAL to PASS. These value rules make the rename insufficient for the providers we touch.
# ClickUp personal API token (pk_<user-id>_<key>; underscore kept in the class for that shape)
(^|[^A-Za-z0-9_-])pk_[A-Za-z0-9_]{20,}
# Linear API key / OAuth access token
(^|[^A-Za-z0-9_-])lin_(api|oauth)_[A-Za-z0-9]{20,}
